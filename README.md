Penguin Data Analysis
Overview
This project analyzes the Palmer Penguins dataset using R.

The project includes:

Data preprocessing
Descriptive statistics
Hypothesis testing
Correlation analysis
Regression modeling
Data visualization
Key Findings
Gentoo penguins are significantly heavier than Adelie penguins.
Male penguins represent approximately 50% of observations.
Flipper length is the strongest predictor of body mass.
The regression model explains about 76% of variation in body mass.
